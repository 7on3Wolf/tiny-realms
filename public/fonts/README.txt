TINY REALM CUSTOM FONTS DIRECTORY
==================================

Place your custom font files (e.g. Pizza Time by MJType) in this folder:
- /public/fonts/PizzaTime.ttf
- /public/fonts/PizzaTime.otf
- /public/fonts/PizzaTime.woff2
- /public/fonts/pizza-time.ttf
- /public/fonts/pizza-time.otf

The @font-face loader in src/index.css is already configured to automatically load these files when available, alongside local installed system fonts and web display fallbacks.
